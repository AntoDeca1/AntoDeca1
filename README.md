## Selected research

**[SwapRec](https://arxiv.org/abs/2609.00913)** &nbsp; · &nbsp; DaQuaMRec @ RecSys 2026<br>
Making sequential recommenders more robust to cold items through training-time swaps with similar warm items.

**[DenseRec](https://arxiv.org/abs/2508.18442)** &nbsp; · &nbsp; EARL @ RecSys 2025<br>
Connecting dense content embeddings with learned item representations for cold-start sequential recommendation.

**[DIVAN](https://github.com/sisinflab/DIVAN)** &nbsp; · &nbsp; RecSys Challenge 2024<br>
Combining personalized interest modeling and news virality to capture temporal dynamics in news recommendation. [Paper ↗](https://doi.org/10.1145/3687151.3687153)
